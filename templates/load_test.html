// how it was run

Who was simulated

  • Visitors, not logged in: the home page, company search, the shop and its product pages.
  • Employees: dashboards, tasks and marking them done, the calendar, the bell, statements, chats and sending messages, each with a live socket open.
  • Owners: company dashboards with the AI panel, the instant "who's best" ranking, and giving tasks with the AI picking up to 5 people.
  • Shoppers: the whole way from a product to a paid order, some fighting over 5 products with only 30 in stock, and some cancelling.
  • 6 people asking the AI questions throughout, and 1 owner asking it who's best for a task. The AI promoter was switched on for 5 companies.
  • Each person waits 1 to 6 seconds between clicks, so 100 people make about 35 requests a second, not 100.
  • {% if rep.stress %}A stress test: new people arrived at up to 5 a second and each one logged in: {% for s in rep.stages if s.kind == 'step' %}{{ s.users }} for {{ '%g'|format(s.minutes) }} minutes{{ ', then ' if not loop.last }}{% endfor %}. Then the crowd dropped to {{ rep.stages[-1].users }} to see the site recover.{% else %}The crowd grew in steps of {{ rep.stages[0].minutes|round|int }} minutes: {% for s in rep.stages if s.kind == 'step' %}{{ s.users }}{{ ', ' if not loop.last }}{% endfor %} people.{% if soak %} Then {{ rep.stages[-2].minutes|round|int }} minutes held at {{ rep.stages[-2].users }} to catch leaks and slow decay, and {{ rep.stages[-1].minutes|round|int }} quiet minutes at {{ rep.stages[-1].users }}.{% endif %}{% endif %}

{# ---------- honest limits ---------- #}

// how to read this

  • Everything shared one computer. {% if rep.notes %}{{ rep.notes.shared }}{% else %}The app, the database, the AI and Locust itself all ran on the machine above, so the AI's heavy CPU use was competing with the website the whole time. A separate AI or database server would do better.{% endif %}
  • One worker process, no network. Requests travelled inside the machine, so real people on real connections would add their own delay.
  • Your limits were on. The rate limiter, spam limits and every other limit ran as they do normally. Each simulated person came from their own local address.
  • Pages, not whole browsers. Locust fetches the page itself, not its pictures, CSS or scripts, which browsers mostly keep in their cache.
  • Not included: video calls and their captions, file uploads, and real emails, SMS or payments (those were printed or pretend, so nothing left the machine).
    • {% if rep.stress %}
  • A short test shows overload, not slow decay. A slow memory leak needs hours to show up, so this test can't rule one out.
    • {% endif %}
  • Percentiles: p95 means 95 of every 100 requests were faster than that number.
